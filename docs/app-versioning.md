# 应用版本管理

每次 AI 成功生成、校验并保存代码后创建不可覆盖的快照。版本号从 V1 开始，失败或停止不创建版本；回退只改变当前版本指针，后续生成使用历史最大版本号加一。

数据库为 app 增加 version、deployedVersion 字段，app_version 保存应用 ID、版本号、生成需求、创建时间和来源。代码保存在 tmp/code_versions/{codeGenType}_{appId}/v{version}，当前预览保持原地址。旧应用在首次读取历史或再次生成前保存为 V1，启动不会批量修改已有应用。

生成、回退和发布共享应用级互斥，数据库行锁保护版本分配。代码先写入独立目录，成功后切换预览；数据库事务失败时恢复上一版预览并清理本次快照。历史版本只读。回退不更改线上文件，需由用户点击更新部署，界面显示当前版本和线上版本。

应用所有者和管理员可读取版本及代码；仅所有者可回退。对比面板显示左右版本、文件列表、行号和增删标记，支持任意两版比较与复制。用户代码按文本渲染，不执行历史代码。历史为空、版本相同、缺失文件、超大文件和网络错误均有明确状态。

升级使用 sql/migrations/20261115_app_versioning.sql（可重复执行）。本地沿用已授权的数据库连接执行迁移并实际验证启动和版本接口。验证包含快照不可变、回退、回退后继续生成、失败补偿、权限、并发互斥和行差异算法。
